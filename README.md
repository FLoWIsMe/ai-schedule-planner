## Installation Instructions
1. Make sure you have node installed {https://nodejs.org/en/download/prebuilt-installer}
2. Make sure you have git installed
3. Make sure you have created an ssh key on github
4. Open your editor of choice (I reccomend using visual studio code)
5. Open a command prompt terminal and cd to the directory where you want to store you project
6. type 'git clone git@github.com:FLoWIsMe/ai-schedule-planner.git'
7. Open this folder in your editor and you can start coding

## Editing the Code
1. Navigate to the github for the project
2. If you have not already, choose an issue to pick up
3. On the right side after you have clicked on a screen, look for the 'Development' section and create a new branch
4. In your text editor, open the integrated terminal and type 'git checkout {the branch you created's name}
5. Make your changes
6. Commit early and often
7. When you finish, create a pull request and add FLoWIsMe as a reviewer
